# NETLEASURE

One falsifiable bet: by August 31, 2027, at least 2 new friends in Fortaleza for no more than 250 leisure hours.

- `STAKE.md` : the frozen claim, how "friend" is measured, checkpoints, known weaknesses.
- `DECISIONS.md` : what was decided and what was thrown away, with reasons.
- `CLAUDE.md` : rules for any session working here.
- `log/hours.template.csv` : layout for the log. The real log goes in `private/`, which git ignores.

No names or personal details of other people are ever committed.
